# Реестр assets

Таблица «файл → фича-потребитель → происхождение/лицензия» (STRUCTURE.md, §4.2).
Значений секретов здесь нет — только служебные ресурсы, принадлежащие
Nix-владеемым компонентам, которые не выражаются как значение внутри самой
фичи.

|---|---|---|
