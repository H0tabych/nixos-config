## 3. Графика (GPU)

### 3.1. Гибридная конфигурация

Ноутбук оснащён двумя GPU, работающими в режиме гибридной графики:

| GPU            | Тип                |
|----------------|--------------------|
| Intel UHD 630  | Встроенный (в CPU) |
| GTX 1650       | Дискретный         |

Дискретный GPU не имеет прямого подключения к встроенной панели
и передаёт кадры через встроенный (схема без MUX-переключателя).
Внешние выходы (HDMI, USB-C с DisplayPort) подключены к дискретному GPU —
подтверждено командой из §11 (см. 6.1).

|-------------------|------------------------|
| Модель            | Intel UHD Graphics 630 |

| Общая память      | Из системной RAM       |
| PCI-шина / ID     | `0000:00:02.0` (`8086:9bc4`) |

### 3.3. Дискретный GPU (dGPU)

| TDP                        | 50 Вт                    |
| PCI-шина / ID               | `0000:01:00.0` (`10de:1f99`) |

### 3.4. Аппаратные ограничения GPU

- Объём VRAM фиксирован — 4 ГБ. Данные, превышающие этот объём,
  в видеопамять не помещаются.
- Отсутствие тензорных ядер: аппаратное ускорение матричных
  операций для ML-нагрузок не предусмотрено.
- Отсутствие RT-ядер: аппаратная трассировка лучей не поддерживается.
- Отсутствие DLSS.
- Compute Capability 7.5 определяет набор доступных операций
  в рамках CUDA и соответствующих библиотек.

## 4. Оперативная память (RAM)

| Параметр                | Значение                       |
|-------------------------|--------------------------------|
| Общий объём             | 24 ГБ (16 + 8)                 |
| Тип                     | DDR4 SO-DIMM, обе планки съёмные — **исправлено**: ранее считалось, что 8 ГБ распаяно |
| Расположение            | Channel A / DIMM0: 16 ГБ Samsung `M471A2K43DB1-CWE`; Channel B / DIMM0: 8 ГБ Crucial `CT8G4SFRA32A`; DIMM1 в обоих каналах — пусто |
| Скорость                | Заявлено 3200 МТ/с, работает на 2933 МТ/с (ограничение платформы) |
| Режим работы            | Асимметричный (Flex Mode)     |
| Максимальная ёмкость    | 64 ГБ по SMBIOS (`dmidecode`); ⚠ расходится с данными ASUS (32 ГБ) — уточнить перед покупкой доп. модуля |

### Особенности

- Обе планки — съёмные SO-DIMM в отдельных слотах (Channel A DIMM0, Channel B DIMM0);
  всего 4 слота, задействовано 2.
- Конфигурация 16 + 8 означает, что двухканальный режим
  действует для первых 16 ГБ (8 + 8 из разных каналов), оставшиеся 8 ГБ
  (из модуля Channel A) работают в одноканальном режиме.
- Пропускная способность памяти неравномерна по объёму:
  в двухканальном сегменте — вдвое выше, чем в одноканальном.
- Платформа работает на 2933 МТ/с, хотя оба модуля рассчитаны на 3200 МТ/с —
  ограничение контроллера памяти CPU (Comet Lake-H), не дефект модулей.

### 6.1. Внешние выходы

| Порт | Заявлено производителем | К какому GPU подключён |
|------|-------------------------|------------------------|
| HDMI 2.0b | 1 шт. | Подтверждено: dGPU (`card0`, шина `0000:01:00.0`) |

- Оба внешних порта закреплены за дискретным GPU (подтверждено, см. §13). Пока к любому
  из них физически подключён монитор, дискретный GPU занят выводом и не переходит
  в состояние suspended. Это ограничение схемы без MUX-переключателя, а не программная настройка.

## 8. Питание и батарея

| Параметр                  | Значение              |
|---------------------------|-----------------------|
| Ёмкость батареи           | 48 Вт·ч (подтверждено расчётом) |
| Блок питания              | 150 Вт               |
| Максимальная нагрузка CPU | 45 Вт                |
| Максимальная нагрузка GPU | 50 Вт                |

### Особенности

- Суммарная мощность CPU + dGPU под полной нагрузкой (≈95 Вт, без остальных узлов)
  разряжает батарею 48 Вт·ч примерно за 30 минут; при активной нагрузке на оба чипа
  автономная работа ограничена этим порядком величин.
- Дискретный GPU, пока он не переведён в состояние suspended (runtime power
  management), потребляет энергию и на батарее.
- Расчёт по данным ядра (`charge_full_design` 4.11 А·ч × `voltage_min_design` 11.68 В ≈ 48 Вт·ч)
  подтверждает паспортную ёмкость. ⚠ При этом `model_name` сообщается как `A32-K55` —
  типовой код стороннего/совместимого аккумулятора, не похожий на оригинальный
  парт-номер ASUS для FX506LH. Проверить физически по этикетке на корпусе батареи.

## 9. Система охлаждения

| Параметр                | Значение                    |
|-------------------------|-----------------------------|
| Конструкция             | Два вентилятора, тепловые трубки |
| Общее охлаждение        | Общий теплопакет CPU + GPU  |

### Особенности

- CPU и GPU охлаждаются общей системой; одновременная нагрузка
  на оба чипа увеличивает температуру каждого из них.
- Троттлинг наступает при достижении температурных порогов,
  заданных производителем.
- ⚠ **Дефект ACPI-таблиц BIOS, подтверждён на машине (R5.1, 2026-10-13):** на
  каждом resume из гибернации (3/3 цикла) в журнале —
  `ACPI BIOS Error (bug): Could not resolve symbol [\_SB.PCI0.LPCB.HEC.ECAV]`
  и следом `acpi-fan PNP0C0B:0{0..4}: PM: failed to restore: error -19` для
  всех пяти вентиляторных ACPI-устройств. Причина — ссылка на несуществующий
  символ в таблицах прошивки, не в NixOS-конфиге; правка потребовала бы
  патча DSDT/SSDT (отдельная рискованная операция, не предпринята). Эффект
  cosmetic: термозоны (`/sys/class/thermal/thermal_zone*/temp`) читаются
  штатно сразу после resume, аппаратная защита EC от перегрева не зависит от
  того, что ACPI отдаёт Linux. Гибернация (STO-5, A13) этим не блокируется.

## 11. Проверка фактов (команды на самой машине)

| Что проверить | Команда |
|---|---|
| Частота обновления и режимы панели | `hyprctl monitors` (или `modetest -c`) |
| К какому GPU подключены порты | `for p in /sys/class/drm/card*-*; do echo "$p $(cat $p/status)"; done`; `ls -l /sys/class/drm/` (карта ↔ шина) |
| Модель Wi-Fi и Bluetooth | `lspci -nn \| grep -i network`; `lsusb`; `bluetoothctl show` |
| Compute Capability и VRAM | `nvidia-smi --query-gpu=name,compute_cap,memory.total --format=csv` |
| Раскладка памяти (8 + 16 ГБ, режим каналов) | `sudo dmidecode -t memory` |
| Паспортная ёмкость батареи | `cat /sys/class/power_supply/BAT*/charge_full_design` (мкА·ч); умножить на `voltage_min_design` (мкВ) |
| Состояние питания dGPU в простое | `cat /sys/bus/pci/devices/<шина-dGPU>/power/runtime_status` |
| Накопитель | `sudo smartctl -a /dev/nvme0` |
