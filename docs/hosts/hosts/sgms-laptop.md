## 3. Графика (GPU)

### 3.1. Гибридная конфигурация

Ноутбук оснащён двумя GPU, работающими в режиме гибридной графики:

| GPU            | Тип                |
|----------------|--------------------|
| Intel UHD 630  | Встроенный (в CPU) |
| GTX 1650       | Дискретный         |

Дискретный GPU не имеет прямого подключения к встроенной панели
и передаёт кадры через встроенный (схема без MUX-переключателя).
⚠ К какому GPU подключены **внешние** выходы (HDMI, USB-C с DisplayPort) — не указано;
на ноутбуках с Optimus они, как правило, заведены на дискретный GPU (см. 6.1).

### 3.2. Встроенный GPU (iGPU)

| Параметр          | Значение               |
|-------------------|------------------------|
| Модель            | Intel UHD Graphics 630 |
| Исполнительные блоки | 24                  |
| Частота           | 350 МГц – 1.15 ГГц    |
| Общая память      | Из системной RAM       |

### 3.3. Дискретный GPU (dGPU)

| Параметр                   | Значение                 |
|----------------------------|--------------------------|
| Модель                     | NVIDIA GeForce GTX 1650  |
| Архитектура                | Turing (TU117)           |
| Compute Capability         | sm_75 (7.5)              |
| CUDA-ядра                  | 896                      |
| Видеопамять                | 4 ГБ GDDR5              |
| Шина памяти                | 128 бит                  |
| Пропускная способность     | 128 ГБ/с                 |
| Тензорные ядра             | Отсутствуют              |
| RT-ядра                    | Отсутствуют              |
| Аппаратный энкодер (NVENC) | 1 блок (лимит одновременных сессий задаёт драйвер) |
| Аппаратный декодер (NVDEC) | Есть                     |
| TDP                        | 50 Вт                    |

### 3.4. Аппаратные ограничения GPU

- Объём VRAM фиксирован — 4 ГБ. Данные, превышающие этот объём,
  в видеопамять не помещаются.
- Отсутствие тензорных ядер: аппаратное ускорение матричных
  операций для ML-нагрузок не предусмотрено.
- Отсутствие RT-ядер: аппаратная трассировка лучей не поддерживается.
- Отсутствие DLSS.
- Compute Capability 7.5 определяет набор доступных операций
  в рамках CUDA и соответствующих библиотек.

## 4. Оперативная память (RAM)

| Параметр                | Значение                       |
|-------------------------|--------------------------------|
| Общий объём             | 24 ГБ                          |
| Тип                     | DDR4 SO-DIMM                   |
| Конфигурация            | 8 ГБ (распаяно) + 16 ГБ (модуль) |
| Режим работы            | Асимметричный (Flex Mode)     |

### Особенности

- Конфигурация 8 + 16 ГБ означает, что двухканальный режим
  действует для первых 16 ГБ (8 + 8), оставшиеся 8 ГБ работают
  в одноканальном режиме.
- Пропускная способность памяти неравномерна по объёму:
  в двухканальном сегменте — вдвое выше, чем в одноканальном.
- Модернизация: штатный объём модели — 8 ГБ (максимум по данным ASUS — 32 ГБ);
  установлен дополнительный модуль на 16 ГБ.

## 6. Дисплей

| Параметр              | Значение              |
|-----------------------|-----------------------|
| Диагональ             | 15.6″                 |
| Разрешение            | 1920 × 1080 (Full HD) |
| Частота обновления    | ⚠ 144 Гц по данным ASUS для FX506LH (ранее указано 60 Гц) |
| Тип панели            | IPS                   |

### Особенности

- Встроенная панель физически подключена к встроенному GPU.
- Кадры, отрендеренные дискретным GPU, передаются на вывод
  через iGPU (отсутствие MUX-переключателя).

---

### 6.1. Внешние выходы

| Порт | Заявлено производителем | К какому GPU подключён |
|------|-------------------------|------------------------|
| HDMI 2.0b | 1 шт. | ⚠ не подтверждено (вероятно, dGPU) |
| USB Type-C (USB 3.2 Gen 1) | DisplayPort / G-SYNC | ⚠ не подтверждено (вероятно, dGPU) |

- Если внешний монитор физически подключён к дискретному GPU, то пока он подключён,
  дискретный GPU занят выводом и не переходит в состояние suspended.
  Это ограничение схемы без MUX-переключателя, а не программная настройка.

## 8. Питание и батарея

| Параметр                  | Значение              |
|---------------------------|-----------------------|
| Ёмкость батареи           | 48 Вт·ч              |
| Блок питания              | 150 Вт               |
| Максимальная нагрузка CPU | 45 Вт                |
| Максимальная нагрузка GPU | 50 Вт                |

### Особенности

- Суммарная мощность CPU + dGPU под полной нагрузкой (≈95 Вт, без остальных узлов)
  разряжает батарею 48 Вт·ч примерно за 30 минут; при активной нагрузке на оба чипа
  автономная работа ограничена этим порядком величин.
- Дискретный GPU, пока он не переведён в состояние suspended (runtime power
  management), потребляет энергию и на батарее.

## 9. Система охлаждения

| Параметр                | Значение                    |
|-------------------------|-----------------------------|
| Конструкция             | Два вентилятора, тепловые трубки |
| Общее охлаждение        | Общий теплопакет CPU + GPU  |

### Особенности

- CPU и GPU охлаждаются общей системой; одновременная нагрузка
  на оба чипа увеличивает температуру каждого из них.
- Троттлинг наступает при достижении температурных порогов,
  заданных производителем.

## 11. Проверка фактов (команды на самой машине)

| Что проверить | Команда |
|---|---|
| Частота обновления и режимы панели | `hyprctl monitors` (или `modetest -c`) |
| К какому GPU подключены порты | `for p in /sys/class/drm/card*-*; do echo "$p $(cat $p/status)"; done`; `ls -l /sys/class/drm/` (карта ↔ шина) |
| Модель Wi-Fi и Bluetooth | `lspci -nn \| grep -i network`; `lsusb`; `bluetoothctl show` |
| Compute Capability и VRAM | `nvidia-smi --query-gpu=name,compute_cap,memory.total --format=csv` |
| Раскладка памяти (8 + 16 ГБ, режим каналов) | `sudo dmidecode -t memory` |
| Паспортная ёмкость батареи | `cat /sys/class/power_supply/BAT*/energy_full_design` (мкВт·ч) |
| Состояние питания dGPU в простое | `cat /sys/bus/pci/devices/<шина-dGPU>/power/runtime_status` |
| Накопитель | `sudo smartctl -a /dev/nvme0` |

| Что | Было | Стало | Основание |
|---|---|---|---|
| Частота обновления дисплея | 60 Гц | ⚠ 144 Гц | Технические данные ASUS для FX506LH; влияет на конфигурацию мониторов |
| Внешние выходы | не описаны | раздел 6.1, ⚠ вероятно dGPU | Влияет на засыпание dGPU (Архитектура, DESK-5, A5) |
| «Нет прямого подключения к дисплею» | для всех выходов | только для встроенной панели | Утверждение не проверено для HDMI/USB-C |

| Bluetooth, модель Wi-Fi | 5.0, AX200 | ⚠ 5.x, AX200/AX201 | ASUS заявляет 5.2/5.3 |
