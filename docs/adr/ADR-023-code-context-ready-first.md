# ADR-23: контекст кода — сначала готовые средства поверх LSP

- Статус: принято
- Источник: AI_SUBSYSTEM.md, раздел 9
- Решение: контекст кода агентам дают готовые средства поверх LSP и
  структурный поиск (уровни L0–L4). Собственный индекс (L5) строится только по
  гейту AI_SUBSYSTEM.md 8.3.
- Причина: не строить без доказанной нужды. LSP уже есть в проектных окружениях
  (DEV-4).
- Затронутые правила: DEV-4, AI-CTX-1, AI-CTX-6, AI-A11

## Решение по гейту 8.3 (R8.9, 2026-11-05)

Гейт не пройден. L5 и роль `local-embed` не делаем (AI-CTX-6).

| Условие гейта | Состояние |
|---|---|
| На наборе 8.2 агенты с L0–L4 не находят контекст в ≥ 30 % задач, подтверждено журналами | Не подтверждено: записи о прогоне набора нет |
| Причина — отсутствие семантического поиска | Не на чем оценивать |
| Есть оценка трудозатрат | Нет |

Замера не было, поэтому решение значит «нужда не доказана», а не «измерено меньше
30 %». Косвенный признак — AI-A11: символьные запросы на шаблонах Python, C/C++ и Rust
совпали с эталоном. Это проверка L2, набор 8.2 она не заменяет.

Вторая часть S8, экспериментальные агенты, уже закрыта: DeepSeek Harness подключён
в R8.6. Новых агентов не добавляем.

Пересмотр: прогон набора 8.2 с журналами и новое решение по трём условиям. При
прохождении гейта — фича по разделу 18.1 Архитектуры и отдельный ADR.
