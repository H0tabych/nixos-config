# ADR-32: user-base — HM-пресет базового окружения пользователя, подключаемый фичей users каждому пользователю независимо от capability

- Статус: принято
- Источник: STRUCTURE.md, Приложение (раздел 13)
- Решение: `user-base` — homeManager-пресет базового окружения пользователя,
  который фича `users` подключает **каждому** пользователю хоста независимо от
  его capability. Состав — homeManager-классы фич этого базиса: `dotfiles-link`,
  `user-dirs`.
- Причина: USER-3 подключает HM-модули только по capability, а конфиги
  (`dotfiles-link`) и стандартные каталоги XDG (`user-dirs`) не привязаны ни к
  одной из них: пользователь без `development` (например, администратор
  headless-хоста) остался бы без них.
- Оболочка, VCS и `env-manager` дают тот же результат через nixos-класс в
  пресете `base`: системный пакет доступен каждому пользователю хоста, поэтому
  homeManager-дубля у них нет (ARCH-5, ARCH-11). Для `shell-zsh` это ещё и
  требование A.6 (HM `programs.zsh` не используется), для `vcs-tools` — git нужен
  nix-фетчеру input'ов до логина и активации Home Manager.
- Затронутые правила: USER-3, ARCH-5, ARCH-11
