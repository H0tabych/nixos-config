# ADR-38: Промпт starship без капсул-фона — обычным текстом, цвет-роль

- Статус: принято (владелец, 2026-10-17)
- Источник: DESIGN_SYSTEM.md §7 (DSN-CMP-12), Приложение P.3.5; ROADMAP R6.9
  (DSN-S6)
- Решение: сегменты промпта starship (каталог, git-ветка, статус VCS,
  длительность команды, код ошибки, окружение) рисуются обычным цветным
  текстом без фона-капсулы и без разделителей-полукругов Nerd Font
  (U+E0B6/U+E0B4). DSN-CMP-12 изменено: было «сегменты-капсулы», стало
  «сегменты обычным текстом без капсул-фона, цвет — роль». Шаблон
  Приложения P.3.5 переписан: убраны `[palettes.glass_tide].surface1` и
  `.on_accent` (были нужны только для фона капсулы и контрастного текста на
  нём), `style` каждого модуля — `fg:<роль>` без `bg:`.
- Причина: живая проверка на машине (R6.9, foot 1.27, пакет
  `nerd-fonts-symbols-only-3.4.0`, `Symbols Nerd Font Mono`) показала, что
  открывающая/закрывающая первую букву соседнего сегмента закрашивает глиф
  U+E0B6/U+E0B4 — подтверждено напрямую: шрифт сам по себе геометрически
  исправен (полукруг отрисован через PIL без искажений), но ink глифа
  специально «вылезает» за границу своей ячейки примерно на 5.5% ширины
  (дизайн Nerd Font — расчёт на бесшовную стыковку), а опция foot
  `tweak.overflowing-glyphs` (умолчание — `yes`) разрешает этому хвостику
  рисоваться поверх соседней буквы вместо обрезки по границе ячейки.
  Отключение `overflowing-glyphs` действительно убирало съедание букв
  (отдельный коммит в dotfiles), но результат владельцу не понравился
  визуально («текст не по центру обводок», «не нравятся эти обводки») —
  решено отказаться от капсул как класса, а не продолжать подбирать обходные
  пути вокруг конкретного глифа.
- Затронутые правила: DSN-CMP-12; не затронуты DSN-COL-8 (состояния по-прежнему
  различимы не только цветом: разные сегменты — разный текст/позиция, код
  ошибки показывается числом), DSN-A13 (критерий отклика ≤ 30/100 мс не
  меняется — набор модулей starship и их таймауты те же, только без
  форматирования capsule-глифов, то есть не медленнее).

## Что меняется

| Было | Стало |
|---|---|
| DSN-CMP-12: «сегменты-капсулы: слева каталог и VCS, справа время выполнения...; цвета — роли» | «сегменты обычным текстом без капсул-фона, цвет — роль: слева каталог и VCS, справа время выполнения...» |
| P.3.5 шаблон: `format = "[](fg:...)...[](fg:...) "`, `style = "fg:on_accent bg:<роль>"` | `format = "[$x]($style) "`, `style = "fg:<роль>"` (без `bg:`) |
| `[palettes.glass_tide]` включает `surface1`, `on_accent` | Только роли, реально используемые текстом: `text`, `subtext0`, `accent_warm`, `special`, `info`, `warning`, `error`, `success` |
| `foot/foot.ini`: `tweak.overflowing-glyphs=no` (обходной путь вокруг капсул) | Настройка остаётся (нужна и без капсул — те же глифы использует yazi для иконок файлов), но перестаёт быть единственной защитой промпта: у промпта глифов-разделителей больше нет вовсе |

## Что не меняется

- Набор модулей и их данные (каталог, ветка, VCS-статус, длительность,
  код ошибки, окружение) — DSN-CMP-12 в этой части не менялось.
- `use_git_executable = true`, таймауты `command_timeout`/`scan_timeout`,
  `starship-lite.toml` без `$git_status` — R.4/DSN-CMP-12 не затронуты.
- tty-промпт (`$TERM = linux`, простой, без starship) — не менялся, у него
  и не было капсул.
- `foot.ini`: шрифт `JetBrains Mono` + `Symbols Nerd Font Mono` fallback —
  всё ещё нужен для yazi и прочих TUI с иконками (P.3.5), не только для
  промпта.

## Альтернативы

- **Оставить капсулы, починить центрирование текста внутри них.**
  Отклонено владельцем: само наличие обводок-капсул не понравилось
  независимо от центрирования — правка центрирования не решала
  настоящий запрос.
- **Капсулы другой формы (острые уголки вместо скруглений).**
  Не выбрано — не предлагалось взамен, отклонено в пользу полного
  отказа от фона-капсулы.
