# ADR-1: Каркас: flake-parts + автоимпорт («dendritic-lite»), фича = файл

- Статус: принято
- Источник: ARCHITECTURE.md §21
- Решение: Каркас: flake-parts + автоимпорт («dendritic-lite»), фича = файл
- Причина: Нет расщепления NixOS/HM и specialArgs; хост — композиция; тело фичи остаётся обычным модулем, откат дёшев
- Затронутые правила: —
