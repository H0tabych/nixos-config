# ADR-3: Dotfiles: отдельный репозиторий, один механизм симлинка, машинный слой

- Статус: принято
- Источник: ARCHITECTURE.md §21
- Решение: Dotfiles: отдельный репозиторий; единственный механизм подключения — симлинк `~/.config/<app>` → рабочая копия (`mkOutOfStoreSymlink`, путь из `dotfiles.source`); машинный слой
- Причина: Правки без пересборки, переносимость на другие дистрибутивы; отдельного read-only режима из flake-input не вводим — он не требуется ни одним критерием (A2 — про сборку системы, не про конфиги приложений) и создавал исключение из A14
- Затронутые правила: DOT-4
