# ADR-20: подсистема — capability `ml`; один бэкенд инференса на хост

- Статус: принято
- Источник: AI_SUBSYSTEM.md, раздел 9
- Решение: подсистема ML и агентов подключается capability `ml`. На хосте один
  бэкенд инференса. Отдельный сервер автодополнения не вводится: клиенты
  обращаются к бэкенду напрямую.
- Причина: ограничение VRAM; два процесса инференса конкурировали бы за одну
  память GPU. Один факт — одно место (ARCH-5). Продолжает ADR-12.
- Затронутые правила: ARCH-5, AI-INF-11, AI-CMP-1, USER-4
