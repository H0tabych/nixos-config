# ADR-42: панель — eww вместо waybar (замена реализации слота `bar`)

- Статус: принято; реализация — ROADMAP.md R9.6 (доработка панели), D14
- Источник: живая проверка на `sgms-laptop` 2026-11-05/06; DESIGN_SYSTEM.md P.3.2, ADR-42 того документа
- Решение: реализация слота `bar` — **eww** (nixpkgs 26.05: `0.6.0-unstable-2026-07-05`).
  Панель, окно сети и календарь — одна конфигурация в dotfiles (`eww/`, запись реестра);
  Nix-часть — фича `bar-eww` (класс H: пакет и два user-юнита, `eww` и `eww-bars`) вместо
  `bar-waybar`. Состав панели прежний (DSN-LAY-2/3), изменено:
  - **один значок сети**: состояние `nmcli` + маршрут туннеля (NET-13, ADR-40); клик —
    окно рядом с панелью: маршрут, Wi-Fi, список сетей;
  - **Bluetooth** — модуль панели (в капсуле сети), включён — `info`; значка blueman в
    трее нет (плагин `StatusIcon` отключён);
  - **раскладка** — отдельная капсула над треем, клик переключает;
  - **календарь** — окно по наведению на часы; колесо мыши меняет яркость и громкость.
- Причина: значок маршрута пропадал в `direct` (кастомный модуль waybar с пустым
  текстом скрывается); окно с переключателями у значка waybar не умеет; Bluetooth в
  трее не читался как состояние панели. Замена затрагивает только фичу-реализацию,
  пресет `desktop` и каталог dotfiles (SLOT-3, A18).
- Затронутые правила: SLOT-3, SLOT-4; DSN-LAY-5 (исключение для Bluetooth); DSN-CMP-5
  (меню маршрута теперь в окне сети); A.3 (суффикс `-eww` у слота `bar`)

## Что изменилось по сравнению с waybar

| Было | Стало |
|---|---|
| Патч `programs.waybar.package` под Lua-диспетчер Hyprland | Не нужен: клик по столу и окну — свой `hyprctl dispatch "hl.dsp.focus({ … })"` |
| `@import url("theme.css")` через симлинк | Один сгенерированный `eww.css`: eww не разрешает относительный `@import` в CSS, а в SCSS нельзя `@цвет` |
| `idle_inhibitor` (протокол Wayland) | `systemd-inhibit --what=idle`; `hypridle` учитывает logind-блокировку |
| Подсказка-календарь, колесо мыши — встроенные | Окно `calendar-popup`; `onscroll` + `swayosd-client` |
| Трей — модуль, значок blueman в нём | `systray` по наведению; Bluetooth — модуль панели |

## Ограничения eww, найденные при внедрении

- Обработчики `onclick`/`onscroll`/`onhover` убиваются через 200 мс (`timeout` по
  умолчанию): rofi, polkit, `bluetoothctl power on` и подобное запускаются отдельным
  сеансом (`eww/scripts/bg`).
- Оверлей-окна размещаются в области после зоны резервирования панели: отступ окна
  считается от её края, а не от экрана.
- Подсказки — только текст; глифы из U+F000–F0FF перекрывает DejaVu Sans.

## Условие пересмотра

- `eww` перестанет собираться в стабильном канале или потеряет поддержку Wayland — вернуть
  waybar (фичи `bar-waybar` и каталога `waybar/` — в истории git: коммиты до `fd52e8f`).
