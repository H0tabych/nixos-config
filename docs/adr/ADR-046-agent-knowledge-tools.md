# ADR-46: знания и инструменты агентов — один формат, один список MCP, память выключена

- Статус: принято; реализация — ROADMAP.md R9.18–R9.22. Дополняет ADR-23
- Источник: решение владельца 2026-11-06 (один формат документов для всех ИИ без согласования между
  ними; память агентов выключена; веб-поиск — свой сервис; `aider` заменяется на `OpenCode`); аудит
  2026-11-06 (D18, D19, D20)
- Решение:
  - **Единый формат инструкций — `AGENTS.md`** в корне репозитория и во вложенных каталогах. Правила,
    которые были в `.claude/rules/*`, вливаются в него. Файла `CLAUDE.md` и `CLAUDE.local.md` рядом с
    ним нет: иначе Claude Code перестаёт читать `AGENTS.md` в этом каталоге. Все три агента читают
    `AGENTS.md` нативно, синхронизировать нечего.
  - **Единый формат навыков — `.agents/skills/<имя>/SKILL.md`.** Для агента, читающего только
    `.claude/skills`, это симлинк на тот же каталог. Для агента, читающего оба каталога, чтение
    `.claude/skills` выключается его переменной. Команды `.claude/commands/*` переводятся в навыки.
  - **Приватная память агентов выключена** (авто-память Claude, память сессий и «сны» агентов):
    знания проекта — только в `AGENTS.md` и `docs/`, где их видят все агенты и человек. Сессии остаются
    локальными журналами и в новые сессии не подмешиваются.
  - **Единый список MCP** — `dotfiles/ai/mcp-servers.toml`; генератор выдаёт форматы всех агентов
    (результат коммитится). Агенты запускаются только с этим списком: пользовательские серверы вне
    списка и серверы из проекта не подключаются (AI-SBX-9). Локальные серверы — внутри песочницы;
    серверы с секретами — через шлюз (ADR-45).
  - **Веб-поиск — свой сервис на loopback** (слот `web-search`, реализация — метапоиск без ключей);
    встроенный поиск агентов, отправляющий запросы на сторону провайдера, выключен. Агент получает
    поиск как MCP-инструмент под нейтральным именем команды.
  - **Общей RAG и собственного индекса нет** (ADR-23, гейт 8.3 не пройден). Общий контекст агентов —
    `AGENTS.md`, `docs/`, LSP и структурный поиск. Если L5 появится, то одним MCP-сервером в общем списке.
  - **Контролируемая роль — `OpenCode`** вместо `aider`. Уровень L4 (карта репозитория внутри агента)
    снят: у `aider` он фактически не работал (модели шлюза), у замены его нет.
- Отвергнуто:
  - **`CLAUDE.md` как канон и импорты из него.** Единственный формат без импортов проще, а чтение
    `AGENTS.md` есть у всех трёх агентов.
  - **Нейтральный формат с генерацией файлов под каждого агента** (`context.yaml` и плагин `dsh`): ещё
    один слой, который нужно сопровождать; у `dsh` есть нативный MCP-клиент.
  - **Общая память агентов** (общий каталог заметок, векторная база): без гейта 8.3 — собственная
    разработка (AI-CTX-6).
  - **Оставить `aider`:** пишет историю и кэш в корень проекта, правит `.gitignore`, записал в
    `.git/config` чужое авторство; читает инструкции только явным `read`.
- Затронутые правила: AI-AGT-1, AI-AGT-3, AI-AGT-7, новое AI-AGT-8, AI-CTX-3, AI-CTX-4, AI-SBX-9,
  AI-A10, новые AI-A15, AI-A16, STR (корень репозитория), DOT-3
- Риски:
  - Навыки у разных агентов принимают разные поля (например, подстановку аргументов): навык без
    расширений читается всеми, расширения — на свой риск.
  - Выключенная память теряет «привычки» агентов: всё нужное записывается в `AGENTS.md` человеком или
    по его решению.
  - Агент, привязанный к семейству моделей, читает глобальные файлы из своего каталога
    (`DSH_AGENTS_HOME`): для него глобальные инструкции берутся из `dotfiles/ai/`.
- Условие пересмотра: гейт 8.3 пройден (L5); либо один из трёх агентов перестаёт читать `AGENTS.md`.
- Проверка: AI-A15 (три агента на одном проекте видят один `AGENTS.md` и одни навыки), AI-A16
  (один набор MCP, `gen.py --check`), AI-A17; `scripts/check-structure.sh`.
