# ADR-33: Этап 4 (оболочка, редактор) продолжается до закрытия Gate G3 Этапа 3

- Статус: принято
- Источник: ROADMAP.md, правило W6 («сначала правило, потом исключение»), раздел 2.3
  (Gate'ы); ARCH-19 (без временных обходов — осознанное отступление оформляется ADR)
- Решение: шаги R4.1–R4.4 (перенос конфигов в dotfiles, `dotfiles-link`, слоты
  рабочего стола, оболочка `shell-zsh`/`vcs-tools`/`env-manager-direnv` и редактор
  `editor-neovim`/`lsp-global`) выполняются, не дожидаясь закрытия Gate **G3**
  Этапа 3 (VPN: выход S3, upstream S4, CI-тест, живое включение клиента — шаги
  R3.5–R3.8 остаются открытыми). Этап 3 доводится до G3 параллельно.
- Причина: рабочий стол, VCS и редактор не зависят от незакрытых шагов VPN (выход,
  upstream, kill switch, живое переключение клиента) и необходимы для MVS (цель
  Этапа 4); откладывать их до G3 не даёт параллельной выгоды и задерживает
  достижимость MVS без снижения риска по сети/секретам.
- Затронутые правила: ROADMAP «Предусловия» Этапа 4 (G3), W6, OPS-7
