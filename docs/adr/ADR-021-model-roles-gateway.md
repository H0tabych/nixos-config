# ADR-21: роли моделей — контракт; пользовательский шлюз как слой индирекции

- Статус: принято
- Источник: AI_SUBSYSTEM.md, раздел 9
- Решение: клиенты обращаются к ролям, а не к моделям и провайдерам. Роль
  разрешает пользовательский шлюз. Dotfiles не содержат констант хоста.
- Причина: модели и провайдеры меняются часто, конфиги клиентов остаются
  переносимыми; ключи пользователя не попадают в конфиги приложений.
- Затронутые правила: DOT-1, DOT-6, USER-7, ML-5, AI-GW-2, AI-A13
- Следствие (R8.8): шлюз обращается к локальному бэкенду только по контракту
  AI-INF-2 — через OpenAI-совместимый API, а не через средство, привязанное к
  реализации слота. Иначе замена реализации потребовала бы правки шлюза (AI-A13).
