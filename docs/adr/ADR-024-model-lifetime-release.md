# ADR-24: конечное время жизни моделей и контракт `inference-release`

- Статус: принято
- Источник: AI_SUBSYSTEM.md, раздел 9
- Решение: время жизни загруженной модели в простое конечно
  (`my.ai.inference.keepAlive`). Команда `inference-release` — контракт слота
  инференса: она освобождает VRAM по требованию, например перед игрой или сном.
  Отдельных режимов машины нет.
- Причина: GPU должна возвращаться в простой и переживать гибернацию (A5, A13);
  потребитель VRAM не должен зависеть от реализации инференса (APP-4).
- Затронутые правила: APP-4, AI-RES-2, AI-RES-5, AI-RES-6, AI-INF-7, AI-A3, AI-A4
