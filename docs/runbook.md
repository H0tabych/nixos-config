# Runbook

Единственная точка входа для операционных процедур (STR-12, OPS-8). Длинные
процедуры по темам — в `runbook/<тема>.md`, со ссылкой отсюда.

Приватные сведения (операторы, уязвимости действующей системы, данные
учётных записей) здесь не хранятся — только вне репозитория (STR-12,
VPN_SUBSYSTEM.md P.6/P.7).

## Темы

- [`runbook/tunnel.md`](runbook/tunnel.md) — туннель: upstream для LLM
  (VPN-LLM-1…6), процедура изменения конфига выхода (VPN-SRV-7)
