# ml-cuda

`cudaPackages.cudatoolkit` под архитектуру хоста (sm_75, GTX 1650), только
кэшируемые бинарные сборки (A.5). Бинарный кэш CUDA подключается системной
фичей `compute-cache` (ML-2) — до первой активации этого шаблона.

```
direnv allow
nvcc --version
```

Перед первой реальной сборкой — `nix develop --dry-run`, чтобы увидеть, что
будет собираться из исходников (должно быть пусто или малó, AI-CC-2).
